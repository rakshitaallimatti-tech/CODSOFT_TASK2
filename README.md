
# Cloud Data Deduplication System

## Description
This project detects duplicate records and stores only unique records using Python and SQLite.

## Features
- Saves unique records
- Detects duplicate email addresses
- Stores data using SQLite
- Exports unique records to CSV

## Technologies Used
- Python
- SQLite
- CSV

## How to Run
Run the task2.py file using Python.

## Output
- Record saved successfully
- Duplicate record not saved
- Unique records exported to CSV
